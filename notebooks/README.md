# Wikipedia corpus exploration

Keep reusable logic in `src/atlasmind` and use notebooks for these experiments:

1. Inspect document lengths, label balance, duplicates, and missing text.
2. Plot TF-IDF sparsity and the most informative terms per topic.
3. Visualize article vectors with PCA.
4. Compare K-Means, hierarchical clustering, and DBSCAN.
5. Plot confusion matrices, ROC curves, and learning curves.
6. Compare PostgreSQL full-text ranking with the fitted local knowledge index.

Store notebook datasets, outputs, and model artifacts under
`/Volumes/Expansion/aiml/atlasmind`, not inside the source repository.
